# HelloKhata Repository Guidelines

Welcome to the **HelloKhata** project repository.

This repository is used to share and manage:

- Source code
- System architecture
- PRD documents
- API documentation
- UI/UX designs
- Feature requirements
- Development notes
- Database schemas
- Deployment guides
- Mobile app resources
- Security rules
- Bug reports
- Roadmaps
- Technical discussions
